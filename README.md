## About Me

I'm a full-stack engineer who ships complete products, not just one layer of them. My most recent build, **Vrede**, is an all-in-one classroom and workspace platform — a React Native mobile app backed by a Python/FastAPI service, PostgreSQL via Supabase, Dockerized deployment on a self-managed VPS, and live release pipelines on both the App Store and Google Play.

I own problems end to end: real-time chat and notification systems, OTA update infrastructure, push notification delivery, CI/CD release automation, and the backend APIs underneath all of it — not just the UI on top.

- 🛠️ Currently building **Vrede**, a full-stack classroom platform (mobile + backend + infra)
- 🎓 Computer Science background, self-taught before going professional
- 🌍 Open to remote opportunities — full-time or contract
- 💬 Happy to talk shop about mobile infra, backend architecture, or shipping fast without breaking things
